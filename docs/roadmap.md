## 待做（按优先级）

### P0 — 信任与正确性

| # | 优化点 | 影响 | 前置 |
|---|---|---|---|
| P0-1 | **定时任务定义持久化** | 进程重启后任务静默丢失，用户以为会一直跑 | 无（自落盘 JSONL，不引 DB） |
| P0-2 | **移除 `application.yaml` 硬编码密钥** | 真实 key 提交进仓库，安全卫生问题 | 无（改环境变量注入） |

### P1 — 功能完整性

| # | 优化点 | 影响 |
|---|---|---|
| P1-1 | **技能恢复接口（unarchive）** | 删除=归档已承诺「可恢复」，却无恢复入口，半成品 |
| P1-2 | **服务端会话列表 / 删除** | 侧栏「移除」只清 localStorage，转录仍留盘 |
| P1-3 | **Agent 定义热加载** | 只支持注册态切换，定义无法运行时增删改 |
| P1-4 | **会话续聊（resume）显式入口** | 复用带未决审批 threadId 需先 resume，当前靠前端兜底 |

### P2 — 锦上添花

| # | 优化点 | 说明 |
|---|---|---|
| P2-1 | token 用量可视化 | 已 emit `token_usage` 事件，前端未展示 |
| P2-2 | 定时任务执行历史 / 日志 | 现在只有 `executions` 计数，无明细 |
| P2-3 | 移动端响应式 | 三栏在窄屏体验差 |

## 明确不做（架构决策）

| # | 项 | 理由 |
|---|---|---|
| N-1 | 数据库 | AgentScope 文件型能力已足够（`design.md` §1） |
| N-2 | 多租户 / 用户体系 / 鉴权 | 单机内部工具，无需求 |
| N-3 | 会话池诊断接口（server-side-memory） | 刻意不启用的组件，暴露会误导 |
| N-4 | `agentscope-admin-spring-boot-starter` | MVC 栈与 WebFlux 冲突 |

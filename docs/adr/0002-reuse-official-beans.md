# ADR-0002：复用官方 Bean，不造 Repository 抽象

- **状态**：已接受
- **日期**：2026-10-11

## 背景

需要提供 agent / 技能 / 定时任务的管理能力，常见做法是包一层「接口 + 文件实现」的 Repository。

## 决策

**直接复用官方 Bean**（`AguiAgentRegistry` / `AgentSkillRepository` / `AgentScheduler`），
在官方能力之上只搭薄层（`agent/` `skill/` `job/` `web/` 四个包）。

## 理由

- 官方能力已覆盖全部需求，再包一层是多余抽象。
- 多余抽象会掩盖真实语义（如技能删除究竟是归档还是硬删）。

## 后果

- 代码路径短，语义直接。
- 官方接口变动时需跟随调整（但官方接口即端口，风险可控）。
